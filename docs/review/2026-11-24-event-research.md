### 2. AI와 Lean 형식 증명: 리만 가설과 양자 알고리즘, 11월 20~23일 (보류 항목 포함 시 11월 10~23일)

- 11월 20일 Anthropic 연구원이자 수학자인 Levent Alpöge는 Claude와 함께 리만 가설(Riemann Hypothesis) 및 디리클레 L-함수에 대한 일반화 리만 가설(Generalized Riemann Hypothesis)의 증명을 찾았다고 밝히며, 4쪽 설명문(`Remark`)과 175,187개 모듈·약 1,700만 줄 규모의 Lean 4 형식 증명 아카이브를 개인 사이트에 공개했다(설명문 타임라인상 GRH 도달 시점은 11월 16일). [Alpöge 설명문 PDF](https://alpo.ge/remark.pdf) (2026-11-24 확인)
- 11월 21일 Lean FRO와 Mathlib Initiative는 공동 성명을 내어 Alpöge의 리만 가설 형식 증명이 Mathlib의 기존 `RiemannHypothesis` 정의와 일치하고 오류 없이 컴파일되며, Lean 공식 커널과 독립 검증기(`con-leche`, `con-ron`, `nanoda` 등)를 통과했다고 인증했다. MIT Andrew Sutherland도 11월 21~23일 독립 재빌드와 표준 공리(`propext`, `Classical.choice`, `Quot.sound`)만 사용함을 확인한 검증 로그를 공개했다. [Lean FRO·Mathlib 공동 성명](https://leanprover-community.github.io/blog/posts/riemann-hypothesis/), [MIT Andrew Sutherland 검증 페이지](https://math.mit.edu/~drew/grh/) (2026-11-24 확인)
- 11월 23일 Google DeepMind와 Google Quantum AI는 Gemini 4 에이전트 팀과 Lean 4 형식 검증을 결합해 관성 가둠 핵융합(연산 비용 11.8배 절감, 오류 정정 큐비트 5,650개에서 4,338개로 축소), 광화학(8배), 약물 대사 효소 Cytochrome P450(2.5배, 481개에서 333큐비트), Grover 알고리즘(2.57배), arcsin 루틴(290배)의 양자 회로를 개선했다고 발표하고 Lean 라이브러리를 GitHub에 공개했다(arXiv 초고 제출일 11월 6일, 블로그·코드 공개일 11월 23일). [Google DeepMind 블로그](https://deepmind.google/blog/finding-faster-quantum-algorithms-with-agents-and-formal-verification/), [arXiv 논문](https://arxiv.org/abs/2611.09822), [GitHub 저장소](https://github.com/google-deepmind/formal-quantum-computation) (2026-11-24 확인)
- 함께 묶을 수 있는 보류 사건은 11월 10일 Google DeepMind의 AlphaProof Code 발표다(11월 13일 노트 후보 5, `libsignal 0.105.4`의 핵심 보안 성질을 기계어 수준까지 Lean으로 형식 증명). [Google DeepMind 블로그](https://deepmind.google/blog/introducing-alphaproof-code/)

기록할 수 있는 문장:

1. (보류 항목 포함 시) Google DeepMind, AlphaProof Code로 Signal 프로토콜 구현의 핵심 보안 성질을 기계어 수준까지 Lean으로 형식 증명했다고 발표.
2. Anthropic 연구원 Levent Alpöge, Claude와 함께 작성한 리만 가설과 디리클레 L-함수 일반화 리만 가설의 약 1,700만 줄 Lean 형식 증명 공개.
3. Lean FRO와 Mathlib Initiative, Alpöge의 리만 가설 증명이 Mathlib 정의와 일치하고 공식 커널과 독립 검증기를 통과했다고 공동 인증.
4. Google DeepMind와 Google Quantum AI, Gemini 4 에이전트 팀과 Lean 형식 검증으로 핵융합·화학·약물 대사 양자 회로의 연산 비용을 줄였다고 발표하고 Lean 라이브러리를 공개.

기존 장면: `2026-09-math-gpt-6`, `2026-10-math-review`, `2026-10-eth-review`(각 4개)는 모두 가득 찼고, `2026-10-rosalind`(3개)는 생명과학 모델 장면이다. 11월 10일 AlphaProof Code까지 4개 사건으로 묶으면 11월 13일 노트의 보류를 해소하면서 보안·순수수학·양자 알고리즘으로 넓어진 Lean 형식 검증 흐름을 한 장면(`science`)으로 정리할 수 있다. 11월 20~23일 3개 사건만으로도 독립 장면이 된다.

### 6. Anthropic, GitHub 풀 리퀘스트 자동화 도구 Claude Ship 베타 공개, 11월 23일

- 11월 23일 Anthropic은 GitHub 풀 리퀘스트(PR)의 코드 검토(`Code Review`, 정식 출시), 실패한 CI 수정과 충돌 해결(`PR Steward`, 베타), 저장소 정책 파일 기반 자동 승인(`Claude Approvals`, 베타)을 묶은 에이전트 제품군 Claude Ship을 베타로 공개했다. [Anthropic 발표](https://claude.com/resources/articles/introducing-claude-ship) (2026-11-24 확인)
- `PR Steward`는 수정 커밋을 올리되 승인·병합 권한은 갖지 않도록 설계했고, `Claude Approvals`는 팀이 정한 정책에 따라 일상적 변경은 자동 승인하고 고위험 변경은 사람 승인을 요구한다. 개발자는 Claude Code에서 `/ship` 명령으로 바로 실행할 수 있다. [Anthropic 발표](https://claude.com/resources/articles/introducing-claude-ship) (2026-11-24 확인)

기록할 수 있는 문장: "Anthropic, GitHub 풀 리퀘스트의 검토·오류 수정과 정책 기반 자동 승인을 묶은 에이전트 제품군 Claude Ship 베타 공개."

기존 장면: `agents` 주제에서 코딩 에이전트의 범위를 코드 작성 이후 승인·병합 단계로 넓힌 사례지만, 단일 기업의 베타 기능 출시다. 경쟁사의 유사한 코드 승인·배포 에이전트 발표가 모일 때 새 장면 후보로 보류한다.

영어 표기: `Claude Ship`, `PR Steward`, `Claude Approvals`는 용어집에 없다. 출처는 위 Anthropic 발표다.

주의: 내부 Claude Code 팀의 PR 병합량 2배 증가·되돌림 40% 감소 수치는 Anthropic 자체 사례 보고이며 외부 검증 수치가 아니다.
