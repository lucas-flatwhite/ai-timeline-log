# 생성형 AI 1,405일

ChatGPT가 공개된 2022년 11월 30일부터 2026년 10월 5일까지, 생성형 AI의 주요 장면 28개를 흑백 목판화 스타일로 찍은 스크롤 연표입니다.

- 첫 화면: 먹판에 새긴 `1,405일`과 햇살 문양
- 장면마다 화면이 고정되고, 배경의 핵심어가 목판 칼선으로 찍혔다가 지워집니다
- 설명판의 세부 항목이 스크롤에 따라 한 줄씩 먹을 입습니다
- 연도 판, 시기별 정리, 연구소별 모델 계보, 출처 포함

## 구조

```
index.html   페이지 전체 (HTML·CSS·JS 한 파일, 빌드 없음)
.nojekyll    GitHub Pages가 Jekyll 처리를 건너뛰도록 하는 빈 파일
```

외부 의존성은 Google Fonts(Black Han Sans, Hahmlet, IBM Plex Mono)뿐입니다. 판화 이미지는 생성 이미지가 아니라 `<canvas>`에서 글자와 도형을 밑그림으로 그린 뒤, 굵기가 변하는 칼선으로 다시 새겨 만듭니다.

## 로컬에서 보기

`index.html`을 브라우저로 열면 됩니다. 폰트 로딩까지 확인하려면 간단한 서버를 쓰세요.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## GitHub Pages로 공개하기

1. 이 폴더를 새 저장소에 올립니다.
2. Settings → Pages → Build and deployment에서 Source를 `Deploy from a branch`, 브랜치를 `main` / `/ (root)`로 지정합니다.
3. 잠시 뒤 `https://<계정>.github.io/<저장소>/`에서 열립니다.

## 내용 고치기

장면 데이터는 `index.html` 아래쪽 `<script>`의 `CH` 배열에 있습니다.

| 키 | 뜻 |
| --- | --- |
| `d` | 눈금자에 찍히는 대표 날짜 (`YYYY-MM-DD`) |
| `when` | 설명판에 보이는 기간 |
| `k`, `t`, `l` | 분류, 제목, 요약 |
| `i` | 세부 항목 `[날짜, 문장]` 목록 (모바일에서는 4개 이하 권장) |
| `g` | 판에 새길 글자 (`\n`으로 줄바꿈) |
| `p` | 칼선 방향: `h` 가로, `d` 사선(`a`에 각도), `w` 물결, `c` 동심원 |
| `m` | 바탕 문양: `rays`, `disc`, `grid`, `fall`, `rise`, 또는 빈 문자열 |

연도 요약은 `YR`, 모델 계보는 `LEDGER`에서 고칩니다. 장면 수가 바뀌면 첫 화면 문구의 “장면 28개”도 함께 고쳐 주세요.
